# Supermarket System with Python
![banner](/assets/images/super.png)

A simple GUI/CLI supermarket management system featuring products, invoices, printing receipts, editing products and more using Python and the built-in Tkinter library for graphical aspects.

# Files
[assets/images](/assets/images)

Assets for this README file such as logos and screenshots

[classes.py](/classes.py)

Defines classes and methods used throughout the application

[data.json](/data.json)

Stores products and information about each product, can be configured manually or through the program

[error_handling.py](/error_handling.py)

Helper file for more efficient CLI debugging

[graphics.py](https://github.com/FaresNawar/SupermarketSystem/blob/main/graphics.py)

Handles the GUI part of the program, includes all graphical aspects in one file

[main.py](/main.py)


Handles the main menu and CLI part of the program

> [!NOTE]
> The program automatically creates `program_settings.txt` 
> upon launch, which stores runtime variables and acts as
> a local database
